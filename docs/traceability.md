# Matriz de rastreabilidade

Revisão 0.25.11, baseline conjunta [SDD-MICROHIL 0.25.11](sdd-versions.md). [spec.md](spec.md) preserva 53 IDs de origem e acrescenta F-23…27/NF-32 (59 requisitos). A sessão de execução e a base Qt avançaram somente os requisitos HOST indicados abaixo; a seleção de saídas numéricas pela GUI também foi testada no HOST. I = mecanismo identificado, não aceitação integral; P = parcial; A = ausente; D = divergente; NA = sem componente.
